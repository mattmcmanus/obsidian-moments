# Demo Vault

Open this folder as a vault in Obsidian and enable the Moments plugin to see how it works.

## What's inside

- **Project notes with inline moments** — `Projects/Home Renovation.md` and `Projects/Book Club.md` have dated headings under their `## Notes` sections
- **A topic note with inline moments** — `Areas/Garden.md` tracks garden updates with dated entries
- **Standalone moment notes** — Dated files like `2026-02-10 - Coffee with Sarah.md`
- **Daily notes** — `Daily/2026-02-10.md` and `Daily/2026-02-12.md`

## Try it out

1. Open this folder as a vault in Obsidian
2. Install and enable the Moments plugin
3. Open the Moments timeline (command palette: "Open timeline")
4. Browse to **February 10** or **February 12** to see how content from project files, standalone notes, and daily notes all appear together
5. Open one of the daily notes and watch the timeline auto-filter to that day
